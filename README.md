# LC-MPBI

**Lean Construction Market Penetration Benchmarking Initiative**

Public site for tracking Lean Construction adoption worldwide.  
Germany 2025 is the first published national benchmark and the reference model other countries adopt.

## Live

Deployed via Vercel from this repository.

## Structure

- `index.html` — single-page site (About, How to Participate, Resources, Benchmark, Contact)
- Status ladder: Existed → Joined → Studied → Published

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```
